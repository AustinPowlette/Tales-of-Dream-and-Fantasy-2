# Probes (headless and GUI regression tests)
Run from a scratch copy, never from the repo: copy `src/Game/*.java` and `tools/probes/*.java` (and `tools/PlaytestProbe.java`, `tools/HelpShots.java`) into one folder, set `startingPopulation = 3000;` in `Map.java` (except for `CompatProbe`, which needs the real size and the old `save.dat` in its run folder), compile with `javac --release 8 -encoding UTF-8`, and run each probe class from an EMPTY directory with `java -Xss512m -cp <out>;lib/flatlaf-3.7.2.jar Game.<Probe>`.
Use ABSOLUTE Windows-style paths in `-cp` (`C:/...`): from Git Bash a relative first entry makes MSYS mangle the whole list and FlatLaf silently drops out.
- Headless: `EconProbe MoveProbe PolishProbe WorldProbe QuestLifeProbe EndFlowProbe PcProbe PcProbe2 QolProbe RulesProbe StartsProbe TextProbe LifeProbe NewProbe SpecProbe Chaos SimProbeX LoreProbe HelpCheck CompatProbe TermFuzz OnboardProbe` (each prints PASS/FAIL lines and a `=====` summary).
- GUI (need a display): `QolGui` (run `QolSeed` first in the same folder: it makes the saved game QolGui continues from), `PcProbeGui` (story off unless a file `../LORE_ON` exists), `MoreGui`, `EndShots` and `GuiUxShots` (screenshots to `-Dshots=<dir>`).
- `CitySim <years>` (cities, sects, city levels, losses and tick phases per year; `-Dtdf.perf=true` for the phases) and `QuestSim <years> <block>` (what NPCs are doing, gear shortage, shelf instruments) are the 2026-10-07 settlement and quest measurements; `GearDiag <years>` prints the gear shortage (unarmed adults, shelves, pools, smiths); `WorldProbe` checks that batch; `QuestLifeProbe` checks the 2026-10-08 quest profiles, fatigue and routine quests.
- `EconSim` (`Game.EconSim <years>`) is the long-run economy measurement (auctions, Potential Pills, Blood, libraries, pools; CSV per year). `tools/HelpShots.java` regenerates `assets/help/*.png`; `tools/PlaytestProbe.java` is the long run (`Game.PlaytestProbe <absolute year>`; the world starts around year 13).
- Timing-dependent checks that can fail once: NewProbe N3/N4, LifeProbe L9, SimProbeX A1/C6, PcProbeGui "Resume continues it".
- 2026-10-09: `UpdateProbe` (Quest Log pruning, meeting a walker, Hunt Monster, Monsters from a beast's kill, Meditate, Inspiration, tournament and treasure notices, scripts that run any command, saved scripts), `SilenceProbe` (runs every button command in a prepared state and lists the ones that print nothing; also the Profession button for every trait), `DialogueProbe` (the words for every voice, the voices, the sixteen scenes and their effects, the conversation, the log lines of the terminal and of an AUTO character, decisions in the speaker's words, people really speaking in a crowded tile) and `DialogueGui` (GUI, needs a display: the Talk window, a decision window, screenshots `dialogue-*.png`). `SpotSim <years>` measures how often the four default spot quests run (it needs the counters patched into a copy of `Character.java`: `spotrun.sh` in the scratchpad does it; the plain game does not call it).

- `BalanceProbe` (2026-10-09): auction bids are a few reserves, not the purse; a new shop has starter stock; a kind of title has ten holders; the Epoch target and the start spread; the trigger throttle keeps the chance per week. `QuestLifeProbe`, `WorldProbe`, `NewProbe`, `EconProbe`, `PcProbe`, `PcProbeGui` and `SimProbeX` switch the throttle (and the shop seeding) off in a static block because they call `quest()` on one character within one week or count a shop's exact goods.

- `PlanProbe` (2026-10-10): planned steps (a turn plans one step, nothing moves until `applyMove`), arrival, a party member riding with the leader, the aim at a walker's planned step (`interceptAim` / `leadAim`), a live Go There that catches a walker, Join Sect cleared when a sect is joined, `invite <id>`, the tournament sign-up for a person who plays, the epoch message and the epoch settings. **Probes that freeze the NPCs set `GameDriver.frozenNpcs = true` in `main` right after `System.setIn(PcProbe.in)`** (not in a static block: that would start GameDriver's `Scanner(System.in)` before the probe's input is set): the NPCs now act before the human prompt of a tick, and one of them could otherwise ask the character a question before the probe is ready (the probe thread then waits for `DecisionBroker`'s lock for ever). With `-Dtdf.parallel=true` the probes run the NPC turns on several cores; run only a few at once (a loaded machine times the long ones out). `-Dtdf.verify=true` makes every tick check the world (`Verify`); `BalProbe` (tools/) is the easiest long run for it: `java -Dtdf.verify=true -Dtdf.parallel=true Game.BalProbe 60` in a 3,000-person copy, then `grep VERIFY out.txt`.

- `SongProbe` (2026-10-11, 36 checks, now also the drum kit and its names, accents and ghost notes, swing, the built-in synthesiser playing every drum piece, channel sharing of `MidiOut` (needs a SoundFont in `soundfonts/` of the run folder), no two songs nearly the same, at least five songs for every kind of place (70 songs now; the night check pins the song it is about); 2026-10-10, 28 checks; headless, no game thread, a few seconds; compile it with `tools/SongTool.java` in the same folder): the songs parse, a song for every mood, no harsh clashes against the chords, the score format (ties, groups, patterns, slash chords, bars that do not add up), performances differ, drums and low pulse in danger and none in the open country, the song thins at night, the main theme fades into the market song when the place changes, rests between songs, never the same song twice running, the built-in synthesiser renders every mood, pinned songs, every mood starts its own song, danger takes over within half a minute, a fixed-layer song plays every track. `SongTool` is also the preview tool: `java --add-exports java.desktop/com.sun.media.sound=ALL-UNNAMED -cp <out> Game.SongTool all music-preview` writes lint, a piano roll, a MIDI file and a WAV (SoundFont) of every song.

- `SongGenProbe` (2026-10-10, 20 checks, needs `SongProbe` and `tools/SongTool.java` in the same folder; a few seconds; points `SongBook.dir` at a temp folder): every arrangement composes songs that pass `SongCheck`, the arrangement of the template is kept, same seed same song, different seeds different songs and titles, the hook returns, keep / reload / broken file / drop, the share in the conductor, and the `music gen|keep|list|share|drop` commands (run by reflection, volume 0). `SongTool gen <arrangement|all> <count> <seed>` prints a batch (title, attempts, length, stepwise share, range, what was thrown away); `SongTool genfiles <arrangement> <seed> <path-base> [wav]` writes its piano roll, MIDI file, score text and optionally WAV.
- `FixesProbe` (2026-10-10, second batch, 44 checks): the hunt mission counter (the `hunt` command and `beastBattleCheck` count, the Quest Log entry follows, the bonus is paid), `spotaction` and `chosenSpot`, `seek talk|court` (and the refusal of a same-gender court), `explore`, the spoilage refund (100%, 50%, 0%, a shop shelf), the Convocation for a sect member against a prize tournament, nobody under 18 dies, the boards (ranks, three tiers of titles, the woman's title, the epoch's exemptions, the `ranking` command).
- `TalesProbe` (2026-10-10, third batch): lint of every story's text (conditions, placeholders, plain sentences), the Heir played on four roads (protection of the people of a story, the choices, skipped chapters, replay), all ten stories played to their epilogue on 12 random roads each, no placeholder left in what was shown, and the five endings of each start.
- `ErasedProbe` (2026-10-10, fourth batch, 19 checks): the Erased: the schedule (one in a century), the warning for a seeker a human knows, the silent removal, the chronicle scrubbed, who remembers (Journal text, scene), a seeker who dies first, a save from before it.
- `ArcsProbe` (2026-10-10, fourth batch, 29 checks): the five seeker arcs end to end, the Defector crossing with its allies, the Teacher passing the lamp, never more than six arcs, a save from before them, the Dimming (friendships lost, the human forgets nothing, the scene) and the later omens.
- `GuiShots2` (2026-10-10, fifth batch): renders the windows of the GUI overhaul to PNG with test data (a display is needed; `-Dshots=<dir> -Donly=<scenes>`). It also shows how to drive the GUI game: commands go through `mv.queueInput`, and `PcProbeGui.SHEETS.clear()` / `PcProbeGui.watch = false` stop the dialog watcher from closing the windows. `PcProbeGui` and `MoreGui` were updated to the new windows (Script Manager, Edit Character, item lists, sheet text).
- `DefendProbe` and `SlimProbe` (2026-10-10, sixth batch): the size of the world, feed policy, skin tone and the defence of sects and cities; husks, relationship / errand caps, the beasts people keep, compressed saves and the memory check. `MemProbe` (a long spectator run of the REAL size: `java -Xmx3g -Xss512m -cp out Game.MemProbe <lastYear> <everyYears> <histogram years>`; `-Dmem.input="n\n20000\nw\n"` chooses the size in the new prompt, `"n\n1\nauto\n"` continues the newest save; writes `mem.csv` with live heap per year, births and deaths) and `tools/SaveStats.java` (what fills a save file; `slim` applies `Slim` and writes a compressed copy) measure memory. `HelpShots -Dshots.load=1` / `PcProbeGui -Dgui.startup="Continue selected"` run the GUI against an old save (give `-Dgui.waitMs`; the saved person is put on MANUAL). A probe copy that sets `startingPopulation = 3000` is not asked for the size.

- `PotentialProbe` (2026-10-11, 24 checks): `Character.givePotential` (the pill cost of every gate, 156 in all, half a pill, a gift that crosses a gate, swallowing a pill), the last two gates (99, and 100 with the 1 in 5 roll), `Reincarnation.GATES`, the epoch's blessing by realm (`epochrealm`, `epochTierCulled`) and `settings crowd`. `TileProbe` (`java -Xmx4g -Xss512m -cp out Game.TileProbe <lastYear> <everyYears>`, the real 100,000 world, writes `tiles.csv`): tile occupancy (median, 90th and 99th percentile, the fullest) and the tiles over 50 / 80 / 100 / 150 / 250 / 400% of the limit, hotspots, cities against their limit, Originis, the potential spread and the people in each realm.
