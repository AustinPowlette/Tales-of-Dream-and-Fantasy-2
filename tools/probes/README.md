# Probes (headless and GUI regression tests)
Run from a scratch copy, never from the repo: copy `src/Game/*.java` and `tools/probes/*.java` (and `tools/PlaytestProbe.java`, `tools/HelpShots.java`) into one folder, set `startingPopulation = 3000;` in `Map.java` (except for `CompatProbe`, which needs the real size and the old `save.dat` in its run folder), compile with `javac --release 8 -encoding UTF-8`, and run each probe class from an EMPTY directory with `java -Xss512m -cp <out>;lib/flatlaf-3.7.2.jar Game.<Probe>`.
Use ABSOLUTE Windows-style paths in `-cp` (`C:/...`): from Git Bash a relative first entry makes MSYS mangle the whole list and FlatLaf silently drops out.
- Headless: `EconProbe MoveProbe EndFlowProbe PcProbe PcProbe2 QolProbe RulesProbe StartsProbe TextProbe LifeProbe NewProbe SpecProbe Chaos SimProbeX LoreProbe HelpCheck CompatProbe TermFuzz OnboardProbe` (each prints PASS/FAIL lines and a `=====` summary).
- GUI (need a display): `QolGui` (run `QolSeed` first in the same folder: it makes the saved game QolGui continues from), `PcProbeGui` (story off unless a file `../LORE_ON` exists), `MoreGui`, `EndShots` and `GuiUxShots` (screenshots to `-Dshots=<dir>`).
- `EconSim` (`Game.EconSim <years>`) is the long-run economy measurement (auctions, Potential Pills, Blood, libraries, pools; CSV per year). `tools/HelpShots.java` regenerates `assets/help/*.png`; `tools/PlaytestProbe.java` is the long run (`Game.PlaytestProbe <absolute year>`; the world starts around year 13).
- Timing-dependent checks that can fail once: NewProbe N3/N4, LifeProbe L9, SimProbeX A1/C6, PcProbeGui "Resume continues it".
