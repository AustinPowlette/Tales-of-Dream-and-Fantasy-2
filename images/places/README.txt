PLACE IMAGES
Recommended size 512x288 (16:9), PNG or JPG, drawn in neutral daylight: the game recolours them from the place name,
the season, the area level and hotspots. Missing files are fine: the game PAINTS a new picture for the place (ArtGen, see Settings).

1) One environment picture per noun in this folder, lowercase with underscores, e.g. hot_springs.png
   Optional biome variant, which wins over the plain one: <noun>_<biome>.png, e.g. mountains_tundra.png
   Biomes: ocean grassland forest desert tundra beach frozen_grassland frozen_desert taiga savanna
2) Overlays in ../overlays (transparent PNG works best): city.png sect.png originis.png (replaces city for the first city)
   dungeon_lost_ruins.png dungeon_beast_lair.png dungeon_martial_trial.png dungeon_haunted_grounds.png dungeon_celestial_trial.png
3) Optional ../moods.txt overrides the adjective -> colour mapping, one per line: `haunted: dark, night`
   Moods: dark fire ice holy arid lush haze blood toxic night vast (empty list = no treatment)
4) _missing.txt (rewritten while you play) lists every place noun the game has shown WITHOUT a hand-made picture (the game paints one),
   then the biome variants you have not made yet (optional: a plain noun picture is used until you do).
